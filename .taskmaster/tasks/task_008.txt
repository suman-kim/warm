# Details:
modules/notification. 주문 모듈은 알림 모듈을 모른다 — 주문 이벤트(order.*)로만 이어진다.
배송 요청 → 그 차종의 운행 중인 기사 전원 / 배차·픽업·배송 완료 → 고객 / 취소 → 배차돼 있던 기사.
data에 type(ORDER_REQUESTED 등)과 orderId가 실린다. Android 채널: new-orders, order-status.
발송은 API 응답을 기다리게 하지 않는다. 재시도는 없다(→ 작업 23).
FIREBASE_SERVICE_ACCOUNT_BASE64가 없으면 발송이 꺼지고 로그만 남긴다.
⚠ 실제 기기 수신은 아직 확인하지 못했다 — Firebase 프로젝트와 앱이 필요하다(→ 작업 11).
(작업 26에서 추가: 메시지·기사 승인·반려 알림, 알림함과 알림 설정, 채널 messages·account.)
