구현 완료. 위치: packages/movo_api (Flutter 패키지).
계획과 달라진 점: 모델은 Swagger 코드 생성이 아니라 서버 응답에 맞춰 손으로 작성했다. 서버 API를 바꾸면 lib/src/models와 lib/src/api를 함께 고치고 tool/integration_test.sh(실제 서버에 붙어 모든 엔드포인트 호출)로 확인한다.
토큰: flutter_secure_storage로 보관. 401이면 자동 갱신 후 같은 요청을 재시도하고, 동시에 여러 요청이 만료를 만나도 갱신은 한 번만 한다(리프레시 토큰은 한 번 쓰면 폐기되기 때문). 리프레시 토큰까지 만료되면 저장된 토큰을 지우고 api.sessionExpired로 알린다.
앱 구분: appRole과 다른 역할의 계정이 로그인하면 받은 토큰을 폐기하고 WrongAppException. 가입은 항상 appRole로 된다.
오류: ApiException(code로 분기 — ApiErrorCode) / NetworkException / UnexpectedResponseException. enum에는 unknown을 둬 서버에 값이 추가돼도 예전 앱이 죽지 않는다.
앱 연결: 각 앱의 lib/api.dart에 api 인스턴스. 서버 주소는 --dart-define=API_BASE_URL (기본 http://localhost:4000/api, Android 에뮬레이터는 adb reverse tcp:4000 tcp:4000).
운영자 API(기사 심사)는 앱이 쓰지 않아 넣지 않았다.
