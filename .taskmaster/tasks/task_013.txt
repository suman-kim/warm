앱만으로 가입 → 등록 신청 → (승인) → 운행 시작 → 주문 수락 → 픽업 → 배송 완료까지 된다.
[2026-10-13] 확인한 것: 화면 테스트 30개(가짜 서버, 디자인과 화면 사진 비교, 360×640·430×932 크기). Android 에뮬레이터에서 실제 서버로 가입 → 서류 → 승인 → 운행 → 새 콜 수락 → 픽업 → 배송 완료 → 수입 → 로그아웃.
이 확인에서 사진 고르기와 기기 위치는 테스트용 값으로 바꿔 끼웠다 — 실제 카메라·사진첩·GPS는 실기기에서 확인해야 한다. iOS에서는 기사 앱을 돌려 보지 않았다.

## 8. 백그라운드 위치 보고 [done]
### Dependencies: 13.3
### Description: 앱이 뒤로 가거나 화면이 꺼져도 운행 중에는 위치를 보낸다.
### Details:
지금은 앱을 쓰는 동안의 위치만 쓴다(권한도 '앱 사용 중'만 요청). 기사가 내비게이션 앱으로 넘어가면 위치 보고가 멈춰, 고객의 배송 추적과 콜의 거리가 멈춘 위치로 계산된다.
할 일: Android 포그라운드 서비스와 ACCESS_BACKGROUND_LOCATION, iOS '항상 허용'과 백그라운드 모드(location). 권한을 왜 쓰는지 안내하는 화면. 스토어 심사에서 사유를 요구한다.
보내는 곳: driver-app/lib/driver_scope.dart (15초 간격), 위치 얻는 곳: services.dart의 DeviceLocation.

[2026-10-15] 구현: LocationSource.watch() — geolocator 위치 스트림. 안드로이드는 '운행 중' 알림을 띄운 포그라운드 위치 서비스(FOREGROUND_SERVICE·FOREGROUND_SERVICE_LOCATION·POST_NOTIFICATIONS 권한), iOS는 UIBackgroundModes location + 백그라운드 위치 표시. 운행을 켜면 스트림을 듣고 15초마다 마지막 위치를 보낸다(켤 때 한 번은 바로). 운행을 끄면 스트림과 서비스가 멈춘다. 에뮬레이터에서 운행을 켜고 홈으로 나가도 포그라운드 서비스(type location)가 도는 것과, 끄면 내려가는 것을 확인했다.
주의: 안드로이드 13+에서 알림 권한을 받기 전에는 '운행 중' 알림이 보이지 않는다(서비스는 돈다) — 알림 권한은 푸시(작업 11)에서 요청한다. 위치 정확도 설정이 꺼진 기기에서 15초마다 위치를 직접 요청하면 구글 설정 창이 계속 떠서, 주기 보고는 스트림 위치만 보낸다. iOS는 아직 돌려 보지 못했다.
