## 14. 외부 주문 연동 (배달앱·POS) [pending]
### Dependencies: None
### Description: 가게가 배민·요기요·쿠팡이츠로 받은 주문을 다시 입력하지 않고 MOVO 배달 요청으로 받는다.
### Details:
[2026-10-15] 조사 (공개 자료 기준 — 조건·비용은 직접 문의해야 한다):
· 배민·요기요·쿠팡이츠는 누구나 쓰는 공개 주문 API가 없다. 2023-11 배달앱 3사·주문통합관리사(푸드테크, 헬로월드)·배달대행사 13곳이 개인정보보호위원회와 '표준 API'를 정했다 — 주문 앱이 배달대행사에 인증키를 주고, 보안 요구사항을 지키지 않으면 거부할 수 있다. 협약 1년, 자동 연장. (etnews.com/20231114000285)
· 주문통합관리 프로그램(포스피드=헬로월드, 푸드테크)이 3사 주문을 모아 배달대행사 40~105곳으로 보낸다. 소규모 대행사는 보통 여기에 연동 대행사로 붙는다. (posfeed.co.kr)
· POS: 공개 API는 토스플레이스만 있다 — 개발자센터 앱을 매장이 설치, 주문·배달 조회, 주문 웹훅, 배달 정보에 손님 주소·연락처와 배달 유형 AGENCY. 배달 정보 쓰기는 Open API로 만든 주문에만 된다. 배달앱 주문의 손님 정보를 읽을 수 있는지는 문서에 없다. 페이히어·OKPOS는 공개 API가 없고 제휴로 대행사를 붙인다. (docs.tossplace.com, payhere.in/food/delivery, okpos.gitbook.io)
· 배민·쿠팡이 자체배달을 늘리며 배달대행사와 갈등이 있다 (한국경제 2025-03) — 신규 대행사 연동이 쉽지 않을 수 있다.
할 일:
1) 토스플레이스 문의 — 배달앱 주문의 손님 주소·연락처를 Open API로 읽을 수 있는지, 배달대행사가 앱을 등록할 수 있는지.
2) 포스피드(헬로월드)·푸드테크 문의 — 연동 배달대행사 등록 조건·규격·비용.
3) 배민·요기요·쿠팡이츠 제휴 창구 — 표준 API 협약 조건.
4) 서버 어댑터: 외부 주문(웹훅) → 외부 매장과 우리 가게를 잇고 → 배달 요청 유스케이스(POST /deliveries와 같은 것)로 넣는다. 주문 채널·외부 주문번호 저장, 같은 주문은 한 번만, 취소 동기화, 표준 API의 개인정보 보안 요구사항(보관 기간·암호화·접근 기록).
5) 가게 앱·PC 웹: 연동한 주문을 자동 요청하거나 한 번 눌러 요청, 조리 시간 입력.
