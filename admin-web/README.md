# MOVO 관리자 웹

운영자가 가게·라이더를 심사하고 배달 관제·충전금·현금 수금·회원·정산·공지·약관을 관리하는 웹 (React · Vite · TypeScript · Tailwind).
가게 앱·라이더 앱·가게 PC 웹과 같은 서버(`../backend`)를 쓴다 — 운영자 API는 `backend/README.md`의 API 표 참고.

화면은 사용자가 준 디자인 파일의 관리자 웹 화면을 옮겼다.

```bash
npm install
npm run dev          # http://localhost:5174 (서버가 떠 있어야 한다)
npm run typecheck
npm run lint
npm test             # 글자 만들기(날짜·금액·번호) 단위 테스트
npm run build
```

서버 주소를 바꾸려면 `.env.example`을 `.env.local`로 복사해 `VITE_API_BASE_URL`을 고친다.

## 처음 켜 보기

```bash
# 1) 서버
cd ../backend && npm run start:local

# 2) 볼 것이 있어야 하니 견본 데이터를 넣는다 (비어 있는 개발용 DB에서만 돈다)
node tool/seed-demo.mjs

# 3) 관리자 웹
cd ../admin-web && npm run dev
```

## 구조

```
src/
├── main.tsx · App.tsx      시작, 주소와 화면 잇기(권한 확인)
├── api/                    서버 호출 (client.ts: 토큰 붙이기·갱신), 응답 모양(types.ts)
├── auth/                   로그인 상태, 로그인 화면, 초대 수락 화면
├── layout/                 왼쪽 메뉴와 틀, 메뉴·권한 이름
├── ui/                     디자인 요소 — 색(index.css), 아이콘, 상태 표(chip), 탭·표·대화상자(kit), 글자 만들기(format)
└── pages/                  메뉴마다 한 폴더
```

- 색·글자 크기·모서리·여백은 디자인 파일의 값을 그대로 썼다. 색 이름은 `src/index.css`의 `@theme`에 있다.
- 글꼴은 SUIT다 (`public/fonts/`, SIL Open Font License).
- 날짜와 시각은 운영자의 컴퓨터가 어느 시간대에 있든 한국 시간으로 보여 준다 (`ui/format.ts`).
- 목록은 100줄씩 받고, 더 있으면 아래에 '더 보기'가 생긴다.

## 디자인과 다른 곳

- **라이더 심사 상세**: 생년월일과 오토바이 연식이 없다 — 라이더 앱이 받지 않는 값이다. 서류 쪽수도 없다. 신청 번호(`A-1048`) 대신 신청 ID의 앞 여덟 자리를 보여 준다.
- **배달 관제**: 주문번호는 `MV` + 날짜 + 배달 ID의 앞 네 자리다 (디자인의 일련번호는 서버에 없다).
- **회원 상세**: 라이더의 평점 칸 대신 진행 중 배달 수를 보여 준다 (평가 기능은 퀵·화물과 함께 뺐다).
- **정산**: 보류는 '계좌 없음'(등록 안 함)과 '계좌 인증 실패'(예금주가 가입자와 다름)로 나눠 보인다. 지급 처리 안내 문구는 지금이 수동 지급이라는 점을 적었다 (서버가 이체하지 않는다).
- **약관**: 시행 중인 판이 없는 종류는 오늘부터 시행하는 판을 올릴 수 있다 (처음 올릴 때). 그 밖에는 디자인대로 내일 이후만 된다.
- **디자인에 없던 것**: 초대받은 사람이 비밀번호를 정하는 화면(`/invite/<토큰>`), 목록의 '더 보기', 불러오는 중·실패 표시. 디자인의 'API 추가 필요' 안내는 API를 만들었으므로 뺐다.

## 아직 실제가 아닌 것

- **초대 메일**: 메일 발송 수단이 없어 초대 링크가 **서버 로그**에 찍힌다 (개발에서만). 그 링크를 초대받은 사람에게 직접 전해야 한다.
- **지급 처리**: 기록만 남긴다 (수동 지급 — 늘 '성공'). 실제 이체는 운영자가 은행에서 따로 한다. PG사 지급대행을 붙이면 '진행 중'·'실패'가 실제로 생긴다.
- **충전금 충전**: 사장님의 실제 충전(포트원)을 붙이기 전이라, 개발 서버에서만 바로 충전된다.

## 화면 테스트

실제 서버에 붙어 메뉴를 돌며 화면이 뜨는지 본다 (Chrome이 설치돼 있어야 한다). 견본 데이터가 든 서버가 필요하다.

```bash
npm run test:e2e                                         # 서버가 http://localhost:4000 일 때
ADMIN_E2E_API=http://localhost:4010/api npm run test:e2e # 다른 주소일 때
```

화면 사진이 `test-results/screens/`에 남는다 — 디자인과 눈으로 견줄 때 쓴다. 데이터를 바꾸지 않는다 (대화상자는 열어 보기만 한다).
견본을 넣은 **당일**의 데이터여야 통과한다 (오늘 배달·배차 지연을 확인한다).
