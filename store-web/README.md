# MOVO 사장님 PC 웹

가게 카운터 PC에서 배달을 바로 요청하고, 진행 중인 배달을 보드로 보는 웹 (React · Vite · TypeScript · Tailwind).
가게 앱(`../customer-app`)·라이더 앱과 같은 서버(`../backend`)를 쓰고, 가게 계정(CUSTOMER)으로 로그인한다.
가게 등록과 심사는 가게 앱에서 한다 — 승인된 가게만 PC에서 배달을 요청할 수 있다.

화면은 디자인 파일(MOVO Delivery Prototype v1)의 '사장님 · PC'를 옮겼다.

```bash
npm install
npm run dev          # http://localhost:5175 (서버가 떠 있어야 한다)
npm run typecheck
npm run lint
npm test             # 글자 만들기(시각·금액·번호·상태) 단위 테스트
npm run build
```

서버 주소를 바꾸려면 `.env.example`을 `.env.local`로 복사해 `VITE_API_BASE_URL`을 고친다.

## 화면

- **배달 보드** — 라이더 찾는 중 · 가게로 오는 중 · 배달 중 · 완료·취소(오늘) 네 칸. 5초마다 새로 받고,
  상태가 바뀌면 알림음과 브라우저 알림(가게 정보에서 켜고 끈다)을 낸다. 배달을 누르면 오른쪽에 상세와 [배달 취소].
- **빠른 배달 요청** — 키보드만으로: 주소 검색(↑↓ Enter) → 상세주소 → 연락처 → 음식값 → 조리 시간(←→)에서 Enter.
  숫자 1·2·3은 결제 방식(선결제 · 만나서 현금 · 만나서 카드).
- **내역** — 오늘·어제·최근 7일·30일(또는 날짜 직접), 완료·취소로 거르고 CSV(엑셀)로 내려받는다.
- **충전금** — 잔액, 충전하기, 충전금 내역. 아직 포트원 가상계좌·카드 충전을 붙이지 않아 개발 서버에서는 바로 충전된다.
- **가게 정보** — 정보 수정(사업자등록번호는 고객센터), 이 PC의 알림 설정.
